# Complexity Calculating RCE

This is a personal project with the aim of assisting students and educators when it comes to the topic of the time complexity of algorithms. It implements two approaches of estimating an algorithms complexity: One rather trivial module measures the execution time of the provided script in regards to its input size and then tries to fit a function to it. (This isn't very scientific but is one way the topic is often introduced in highschool level CS classes)
The second approach analyses the syntax trees of languages and calculates the complexity by counting the number and evaluating the structure of operations.
